# Job Portal Application

A Java Full Stack web application developed to connect job seekers and recruiters through an online job portal.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- JSP
- HTML, CSS, JavaScript
- MySQL
- Maven

## Features
- User registration and login
- Job seeker and recruiter modules
- Job posting and management
- Job application functionality
- Profile management
- Admin module
- Email notifications

## Project Structure
- Controller – Handles application requests
- Service – Contains business logic
- Repository – Handles database operations
- DTO – Manages application data
- JSP – Provides the user interface

## Database
MySQL is used to store application data.

## How to Run
1. Clone this repository.
2. Import the project into Eclipse as an existing Maven project.
3. Configure your MySQL database.
4. Update the database credentials in your local application configuration.
5. Run the Spring Boot application.
6. Open `http://localhost:8080/` in your browser.
